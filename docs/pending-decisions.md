# 보류 중인 결정사항

## 1. 측정 도구 선택 ⚠️ **HIGH PRIORITY**

### 참을성/집중력 측정 방법

#### Option A: SART (Sustained Attention to Response Task)

**설명**:

- 지속적 주의력 측정 과제
- 화면에 빠르게 나타나는 숫자(또는 문자)에 대해 특정 숫자(예: "3")가 나타날 때만 클릭하지 않고 나머지는 모두 클릭

**장점**:

- 학술적으로 검증된 방법
- 지속적 집중력 측정 가능
- 구현 비교적 간단
- 정량적 지표 명확 (정답률, 반응 시간, omission/commission errors)

**단점**:

- "참을성"보다는 "집중력" 측정에 가까움
- 지루함을 유발할 수 있음
- 반복 측정 시 학습 효과 발생 가능

**측정 지표**:

- 정답률 (Accuracy)
- 평균 반응 시간 (RT)
- Commission Error (눌러야 할 때 안 누름)
- Omission Error (안 눌러야 할 때 누름)

#### Option B: Unsolvable Task (불가능한 과제)

**설명**:

- 실제로 풀 수 없는 문제를 제공하고, 참가자가 얼마나 오래 시도하는지 측정
- 예: 풀 수 없는 퍼즐, 불가능한 패턴 찾기

**장점**:

- "참을성" 직접 측정 (persistence)
- 실제 문제 해결 맥락과 유사
- 포기 시점까지의 시간 측정 용이

**단점**:

- 참가자에게 심리적 스트레스 가능성
- 윤리적 고려 필요 (디브리핑에서 실제로 불가능했다고 설명)
- 반복 측정 시 참가자가 패턴을 눈치챌 수 있음
- 측정 지표 정의가 애매함

**측정 지표**:

- 과제 지속 시간 (Time to Give Up)
- 시도 횟수 (Number of Attempts)
- 포기 여부 (Binary: Gave Up / Completed Timer)

#### Option C: 혼합 접근

**설명**: Pre에서 SART, Post에서 Unsolvable Task (또는 반대)

**장점**: 두 가지 측면 모두 측정 가능

**단점**: 데이터 분석 복잡도 증가

## 2. 시간 제약 조정 ⏱️

### 현재 설정

- 각 과제 제한 시간: **5분 (Hard Limit)**
- AUT 수행 시간: **2분**
- 전체 실험 시간: 약 **30분**

### 검토 필요 사항

- [ ] 5분이 적절한가? (너무 짧거나 너무 긴가?)
- [ ] 파일럿 테스트 후 조정 필요 여부
- [ ] 수학/글쓰기 문제 난이도에 따라 시간 차등 적용 가능성

### 시간 분배 (참고)

```
1. 시작 화면: 0.5분
2. IRB 동의서: 1분
3. 참가자 정보: 1분
4. 실험 안내: 1분
5. Pre-측정 안내: 0.5분
6. AUT (Pre): 2분
7. 참을성 측정 (Pre): 3~5분 (도구에 따라)
8. 과제 1 안내: 0.5분
9. 과제 1 수행: 5분
10. Mid-측정 안내: 0.5분
11. AUT (Mid): 2분
12. 참을성 측정 (Mid): 3~5분
13. 과제 2 안내: 0.5분
14. 과제 2 수행: 5분
15. Post-측정 안내: 0.5분
16. AUT (Post): 2분
17. 참을성 측정 (Post): 3~5분
18. 종료 화면: 1분

총계: 29~35분
```

## 3. 수학/글쓰기 문제 세부 설계 📝

### 현재 상태

- **그룹**: 수학 vs. 글쓰기
- **문제 버전**: A vs. B (각 그룹 내 2개 문제)
- **구체적 문제 내용**: **미정**

### 결정 필요 사항

#### 수학 문제

- [ ] 문제 유형: 확률/통계? 미적분? 조합/경우의 수? 응용 수학?
- [ ] 난이도 수준: 고등학교 수준? 대학 교양 수준?
- [ ] 예시 문제 A/B 준비
- [ ] LLM 사용 시 실제로 도움이 되는 난이도인가?

**추천 방향**:

- 단순 계산보다는 **개념 이해 + 응용** 필요한 문제
- LLM이 접근법 제안 가능하지만 최종 풀이는 학생이 해야 함
- 5분 내에 풀 수 있는 난이도

#### 글쓰기 문제

- [ ] 문제 유형: 논증 에세이? 설명문? 창의적 글쓰기?
- [ ] 주제: 시사적? 철학적? 일상적?
- [ ] 예시 문제 A/B 준비
- [ ] LLM 사용 시 어떤 도움을 기대하는가? (아이디어 브레인스토밍? 구조 제안?)

**추천 방향**:

- 짧은 에세이 (200-300단어)
- 명확한 입장 표명 필요한 주제
- LLM으로 논점 정리 가능하지만 최종 작문은 학생이 해야 함

#### 문제 균형성 확인

- [ ] A와 B의 난이도가 비슷한가?
- [ ] 두 문제 모두 LLM 사용으로 유사한 수준의 도움을 받을 수 있는가?
- [ ] 파일럿 테스트 계획

#### 정답 평가 방식 ⚠️ 중요

**데이터 구조 반영됨** (`task_data` 시트):

- `correct_answer`: 연구자가 사전에 정의한 정답 또는 모범 답안
- `is_correct`: 연구자가 답안 검토 후 정답 여부 판정 (TRUE/FALSE/NULL)
- `score`: 부분 점수가 필요한 경우 0~100 점수 부여 (선택사항)
- `evaluation_notes`: 평가 시 특이사항이나 메모 기록 (선택사항)

**결정 필요**:

- [ ] 정답 평가 기준 명확히 정의
- [ ] 수학/글쓰기 각각의 채점 루브릭 작성
- [ ] 부분 점수 부여 방식 결정 (0/100만? 또는 세부 점수?)
- [ ] 평가자 간 신뢰도 확보 방안 (복수 평가자? 가이드라인?)

## 4. AUT 물건 선정 🧱📎🥤

### 현재 설정

- 물건 3가지: **벽돌, 클립, 종이컵**
- **카운터밸런싱 적용**: 6가지 순서로 회전 배정 (순서 효과 제거)
  - 참가자 0: 벽돌(Pre) → 클립(Mid) → 종이컵(Post)
  - 참가자 1: 벽돌(Pre) → 종이컵(Mid) → 클립(Post)
  - 참가자 2: 클립(Pre) → 벽돌(Mid) → 종이컵(Post)
  - ... (총 6가지 순열)

### 검토 필요 사항

- [ ] 이 세 가지 물건이 창의력 자극에 적절한가?
- [ ] 참가자들이 익숙한 물건인가?
- [ ] 문화적 편향은 없는가? (KAIST 학생들에게 모두 친숙한가?)
- [ ] 세 물건의 창의력 자극 난이도가 비슷한가?

### 대안 물건 후보

- 신문지
- 고무줄
- 나무 막대
- 빈 병
- 휴지
- 등등...

### **팀 결정 필요**

- [ ] 현재 물건(벽돌/클립/종이컵) 유지 또는 변경
- [ ] AUT 문헌에서 일반적으로 사용되는 물건 조사
- [ ] 세 물건 간 난이도 균형 확인

## 5. LLM 사용 안내 방식 🤖

### ✅ 확정 사항

- **LLM 사용 방법**: 참가자가 **브라우저를 직접 열어** 사용 (Gemini, ChatGPT 등)
- **역할**: **"협업 파트너"**, 답안 생성기 아님
- **기술적 구현**: API 연동 없음, 별도 인터페이스 구현 불필요

### 검토 필요 사항

#### 화면 안내 문구

- [ ] 과제 시작 전 안내 화면에 표시할 LLM 사용 가이드라인:
  - "LLM을 자유롭게 사용할 수 있습니다"
  - "힌트, 아이디어, 접근법을 얻는 데 활용하세요"
  - "하지만 최종 답안은 직접 작성해야 합니다"
  - 추가 문구 필요?

#### 사용 권장사항

- [ ] 특정 LLM 권장 여부 (gemini pro 2.5로 고정)

#### 데이터 수집

- [ ] LLM 사용 여부만 기록? (Yes/No)
- [ ] 참가자에게 "LLM을 사용했나요?" 질문?
- [ ] 사용 횟수, 질문 내용 등은 수집하지 않음 (확정)
